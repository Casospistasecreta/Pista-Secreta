---
name: Quiz metadata
description: User-approved source of truth for case duration, player count, and difficulty shown in quiz recommendations.
---

Quiz case metadata should mirror the landing cards. Map the card's difficulty scale as 2/5 = Easy, 3/5 = Moderate, and 4/5 = Advanced.

**Why:** The user chose matching the cards so the same case does not show conflicting details in different parts of the site.

**How to apply:** When the landing card's duration, player count, or difficulty changes, update the quiz's pt-BR, English, and Spanish values too. Do not change cards, prices, or checkout links unless the user asks.
